# 패드64

브라우저에서 손가락으로 두드려 음악을 만드는 8×8 패드입니다.
**파일 하나, 외부 라이브러리 0개, 빌드 없음.** 소리는 전부 브라우저가 실시간으로 합성합니다.

👉 **[지금 바로 열기](https://pad64.vercel.app)**

거울 주소: [reinhardt7177-lab.github.io/pad64](https://reinhardt7177-lab.github.io/pad64/)

태블릿·폰에서도 그대로 됩니다. 화면 방향에 맞춰 칸이 늘어납니다.

### 소리 묶음 세 가지

- **기본** — 드럼·베이스·화음·멜로디 각 8가지, 라단조
- **디스코** — 프렌치 하우스. 킥마다 다른 소리를 눌러주는 **사이드체인 펌핑**과 16마디에 걸쳐 열렸다 닫히는 **필터 스윕**
- **디제이** — EDM 리믹스. 톱니 일곱 겹을 쌓은 **슈퍼소**, 미끄러져 내려오는 **808 서브**, 필터가 출렁이는 **웝 베이스**, 포먼트로 사람 소리를 흉내낸 **보컬 칩**, **에어혼**과 **스크래치**

#### 디제이는 5×5 전용 보드입니다

**오른쪽 모드 기둥으로 같은 칸의 역할을 바꿉니다.** 20개 연주 칸과 5개 모드·정지 버튼을 사용합니다. 루프는 `패턴 1–4 / 5–8` 버튼으로 각 파트의 8가지 패턴을 모두 선택할 수 있습니다.

| 모드 | 20칸이 하는 일 |
|---|---|
| **루프** | 드럼·베이스·화음·멜로디 8가지씩(한 페이지에 4개) + 효과음 4개 |
| **반복** | **누르고 있는 동안만** 그 줄의 악기를 1/4·1/2·1·2박 간격으로 다시 칩니다. 오디오 구간을 캡처하는 루프 롤이 아닌 노트 반복입니다. 손을 떼면 원래 패턴으로 돌아갑니다 |
| **샘플** | 원샷 20개 — 북, 에어혼, 스크래치, 808, 슈퍼소… |
| **음** | 라 시 도 레 미 파 솔 20칸을 슈퍼소로 연주합니다. 기본은 누르는 동안 유지하며, 설정에서 짧은 원샷으로 바꿀 수 있습니다 |
| **정지** | 루프·반복·누른 음·예약 음·잔향을 모두 끔 |

칸 크기는 화면에 맞춰 바뀝니다. 빠르기와 장면은 그리드 옆/위 조작 띠에서 조절합니다. 키보드는 `Shift+숫자`도 작동하며, MIDI velocity는 소리 강약에 반영됩니다.

연주 중에 묶음을 바꿔도 소리가 끊기지 않습니다. 클립 번호는 그대로 두고 내용만 갈아끼웁니다.

## 어떻게 만들어졌나

앱은 `index.html` 한 파일에 들어 있습니다. 개발용 검증 코드는 `tests/`에 분리되어 있으며 앱은 외부 라이브러리를 로드하지 않습니다.

| 부분 | 내용 |
|---|---|
| 오디오 엔진 | 북·신스를 파형부터 합성. 킥과 나머지를 다른 버스로 갈라 사이드체인을 구현 |
| ZIP 리더 | 라이브러리 없이 중앙 디렉터리를 직접 파싱. 압축 해제는 브라우저 내장 `DecompressionStream` |
| 유니팩 | `info` / `keySound` / `autoPlay` 해석 |
| 시퀀서 | 오디오 시계에 미리 예약합니다. BPM 변경은 아직 예약하지 않은 스텝부터 적용하며 원샷도 같은 격자를 씁니다. 타이머가 밀리면 과거 스텝은 건너뛰고 현재 위치로 복귀합니다 |
| 저장 | IndexedDB. 유니팩은 원본 zip만 보관해 용량을 아낍니다 |
| 입력 | 멀티터치, 손가락 훑기, Web MIDI |

### 곡 생성기도 함께 들어 있습니다

패드와는 별개로, **파이썬 표준 라이브러리만으로 파형부터 합성해 곡을 만드는** 스크립트가 있습니다. numpy도 안 씁니다.

```bash
python ballad.py   # 감성 발라드   B minor  1분 34초
python rock.py     # 록 발라드     E minor  2분 5초
python spy.py      # 스파이 액션   5/4박자  1분 46초
```

`rock.py` 의 기타는 Karplus-Strong 으로 줄을 튕겨서 디스토션과 캐비닛 필터에 통과시킨 소리입니다. `spy.py` 는 5/4박자를 3+2로 쪼개 절뚝거리는 그루브를 만듭니다.

완성된 mp3 4개도 같이 들어 있습니다.

### Strudel 버전

`*.strudel.js` 는 [strudel.cc](https://strudel.cc) 에 붙여넣으면 실시간으로 연주되는 라이브 코딩 버전입니다.

## 직접 실행하기

`index.html` 을 브라우저로 열면 됩니다. 다만 **마이크 녹음과 저장은 `https` 나 `localhost` 에서만** 동작하므로, 로컬에서 쓸 때는 서버로 띄우세요.

```bash
python -m http.server 8765
```

그 다음 `http://localhost:8765` 로 접속합니다.

## 알려진 제약

- 마이크는 `https` / `localhost` 에서만 열립니다
- 저장은 브라우저·기기별입니다. 다른 기기로 옮겨가지 않습니다
- 라이트쇼의 무한 반복은 4회로 잘라서 재생합니다
- 내보낸 유니팩의 소리는 16비트 wav 로 다시 구워집니다 (명세가 wav 를 요구합니다)
- 유니팩마다 Y축 기준이 달라, 배치가 뒤집혀 보이면 설정에서 **Y축 뒤집기**를 켜세요
- 백그라운드 탭·화면 잠금·OS 절전에서 연속 재생은 브라우저 정책에 따라 달라집니다
- 원곡 BPM·첫 박은 직접 지정합니다. 자동 BPM 감지 및 음정을 유지하는 time-stretch는 제공하지 않습니다
- 믹서는 현재 세션에 적용됩니다. 유니팩 내보내기는 원본 샘플을 사용하며 믹서 설정을 굽지 않습니다
- 장면은 내장 신스용입니다. 연주 전체 녹음, 오디오 구간 캡처형 롤은 별도 기능입니다

## 수정 검증

```powershell
node --test tests/transport.test.cjs
node tests/serve.cjs
```

두 번째 명령 실행 후 `http://127.0.0.1:8877/tests`를 열면 실제 `OfflineAudioContext`로 출력 없이 오디오를 렌더링해 검증합니다. 결과는 화면과 `tests/artifacts/results.json`에 기록됩니다. `/`에서는 앱을 확인할 수 있습니다. 서버는 앱과 검증 화면만 제공하며 환경변수 파일이나 Git 메타데이터는 제공하지 않습니다.

검증은 입력 해제·박자 변경·늦어진 스케줄러·샘플 경계, 비상 정지 후 무음·재시작·velocity·파트 mute·대표 믹스 peak를 다룹니다. 실물 MIDI 및 휴대폰 오디오 지연, LUFS·true peak 인증을 대체하지 않습니다.
