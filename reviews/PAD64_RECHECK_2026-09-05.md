# 패드64 PR 재점검

검토 대상: PR #1의 최초 수정 커밋 `6c03aef`. 연주 중 입력 전환, 비동기 오디오 종료, 보드 저장·복원에 집중했다. 추가로 재현한 6가지 문제를 같은 PR에서 수정했다.

## 추가 발견과 수정

| 문제 | 재현 조건과 영향 | 수정 |
|---|---|---|
| 훑기 중 비상 정지 | DJ 효과음 행에서 손가락을 정지 칸으로 이동하면 연주 전체가 끊김 | 훑기 대상에서 DJ 모드·정지 열 제외. 직접 누르기는 유지 |
| 새 미리 듣기가 갑자기 정지 | 재생→정지→재생 후 이전 소스의 종료 콜백 도착 | 현재 미리 듣기 소스와 일치하는 종료만 처리 |
| 중단한 샘플이 페이지 이동 | wormhole이 있는 샘플을 정지한 뒤 종료 이벤트 발생 | 명시적 중단 여부와 보드·모드 확인. 정상 종료의 페이지 이동은 유지 |
| 저장 후 라이트쇼 누락 | 유니팩 저장→다시 열기→내보내기에서 keyLED 손실 | LED 이벤트를 독립 복사해 저장·복원. 필드가 없는 예전 저장본은 원본 ZIP에서 읽기 |
| 다른 보드의 되돌리기 적용 | 배치를 수정한 뒤 다른 보드를 열고 되돌리기 | 보드 생성·가져오기·복원 시 되돌리기 기록과 기존 라이트쇼 타이머 초기화 |
| 이전 보드의 오디오가 새 보드에 섞임 | 디코딩 또는 파일 배치 중 보드 전환 | 시작한 보드·캐시·작업 큐를 확인하고 오래된 결과 무시. 복원 준비 후 보드와 캐시를 함께 교체 |

라이트쇼가 이미 누락된 ZIP으로 내보내진 경우, 원본 keyLED가 없으면 복구할 수 없다. 원본 ZIP이 남은 예전 보드 저장본은 복원 가능하다.

## 검증

최초 추가한 6개 재현 검사는 수정 전 모두 실패했고 수정 후 통과했다. 관련 비동기 작업과 복원 실패 검사를 보강해 Node 회귀 검사는 총 21개다.

```powershell
node --test tests/transport.test.cjs tests/lifecycle.test.cjs
node tests/serve.cjs
```

- Node: **21/21 통과**. 앱 JavaScript 구문, 입력·타이밍, 보드 소유권, 오래된 콜백, 저장 데이터 검사 포함.
- 실제 Chromium 브라우저 `/tests`: **13/13 통과**, 미처리 오류 없음.
- 실제 IndexedDB에 전용 임시 레코드를 저장하고 복원한 뒤 ZIP 재내보내기 확인. LED 색 `#FF0000`, 100ms 간격, 반복 2회와 keyLED 파일 유지. 임시 레코드는 검사 후 삭제하며 자동 저장은 비활성화.
- 실제 OfflineAudioContext 종료 이벤트: 중단한 샘플은 현재 페이지 유지, 정상 종료는 지정된 페이지로 이동.
- 기존 오디오 검사도 재실행: 비상 정지 후 sample peak/RMS 0, 재시작 전 이전 잔향 없음, 파트 mute 후 출력 0.
- 대표 네 파트 + 에어혼 6회 출력: sample peak 약 0.708 / **-3.00dBFS**. 측정 조건은 최초 수정 보고서와 동일하며 난수 리버브 때문에 실행마다 조금 달라짐.
- `git diff --check` 통과. GitHub Actions 실행 대상에 새 회귀 검사 파일 추가.

실물 MIDI, 휴대폰 오디오 지연, LUFS·true peak와 청감 마스터링은 이번 재점검의 측정 범위에 포함하지 않았다. 화면 레이아웃은 변경하지 않았다.
