# 패드64 점검 후 수정 결과

기준: [수정 전 점검](PAD64_DJ_REVIEW_2026-09-05.md), 원본 커밋 `17b32b3`.

## 해결 내역

| 점검 항목 | 적용 결과 |
|---|---|
| 원샷 지연 | 기본 즉시 재생. 1/8·1/16 보정은 선택 사항 |
| BPM 변경 시 격자 불일치 | 예약이 끝난 다음 스텝에 템포 변경을 적용하고 수동 입력도 같은 템포 구간 사용 |
| 타이머 지연 후 과거 음 몰림 | 지난 스텝을 건너뛰고 현재 박자로 복귀 |
| 반복 해제·다중 입력 | 포인터·물리 키·MIDI 입력별 소유권 추적. 마지막으로 누른 반복을 우선하고, 해제 시 이전 반복 복귀 |
| 모드 전환·포커스 상실 | 누른 음과 반복 상태 해제. 늦은 keyup이 다른 패드를 끄지 않음 |
| 비상 정지 | 현재·미래 오디오 소스 종료, 12ms 출력 페이드, 새 오디오 연결로 잔향 재등장 방지 |
| Shift+숫자 | `KeyboardEvent.code` 사용. Shift를 먼저 놓는 경우도 동일 입력을 해제 |
| MIDI 강약·표시 | velocity를 dry/wet 음량에 반영. 모드별 LED 색 및 5×5 밖 LED 초기화 |
| 화면에서 사라지는 활성 패턴 | DJ 루프 1–4 / 5–8 페이지 제공, 활성 패턴 이름 표시 |
| 모드별 이름·색 | 샘플/음 모드의 행 이름·접근성 이름·패드 색상 수정 |
| 정지 버튼 색상 | 누락된 전용 색상과 붉은 테두리 적용 |
| 고정 길이 음 | 음 모드에서 누르는 동안 유지, 설정으로 짧은 원샷 선택 |
| 롤 설명 불일치 | 실제 동작에 맞춰 ‘반복’으로 명명하고 노트 재타격임을 안내 |
| 파트별 믹싱 | 5개 파트 음량·저역통과 필터·잔향 조절. 기본 레벨 및 출력 여유 조정 |
| 음악 전개 | Intro/Groove/Build/Drop을 다음 마디에 일괄 적용, 16마디 위치와 대기 상태 표시 |
| 샘플 박자 기준 | 원곡 BPM·첫 박 수동 입력 및 1·2·4·8박 선택. 파일 끝을 넘지 않도록 제한 |
| 샘플 절단 클릭 | 선택 가능한 3ms 경계 페이드. 미리 듣기와 저장에 같은 처리 적용 |
| Cmaj7 설명과 실제 음 불일치 | 디스코 마지막 화음에 B를 포함하도록 수정 |
| 과장된 연속 재생 보장 | 브라우저 백그라운드·절전 제약을 README에 명시 |

검증 중 추가로 같은 파일명 음원 배치의 충돌 가능성을 줄이고, 종료된 자동연주의 늦은 화면 이벤트를 무효화했다. 마이크 녹음은 시작한 입력만 해제 시 중단하도록 했다.

## 검증 결과

- `node --test tests/transport.test.cjs`: **12/12 통과**.
- `node tests/serve.cjs` → `/tests`: 실제 브라우저 `OfflineAudioContext` 기반 **11/11 통과**.
- `git diff --check`: 통과.
- 1280×720 데스크톱 및 390×844 휴대폰 크기에서 기본/DJ 화면 확인.
- GitHub Actions에 Node 회귀 검사 추가. 브라우저 오디오 검사는 로컬 검증 페이지에서 실행한다.

브라우저 출력 검사의 대표 측정값:

| 시나리오 | 측정 결과 |
|---|---|
| 0.25초에 비상 정지 후 0.29–1.5초 구간 | sample peak 0, RMS 0 |
| 비상 정지 후 새 음을 치기 전 구간 | sample peak 0, RMS 0 |
| 화음 파트 mute, 리버브 send 포함 | sample peak 0 |
| 808 velocity 0.2 / 1.0 | RMS 약 0.057 / 0.249 |
| DJ 네 파트 + 에어혼 6회, 5초 렌더 | sample peak 약 0.710, 약 -2.97dBFS |

테스트는 기본 믹서 음량 75%, 마스터 80%, 출력 계수 0.65, 44.1kHz 스테레오에서 진행했다. 리버브 임펄스는 난수를 사용하므로 수치는 실행마다 조금 달라진다. 대표 믹스의 sample peak는 모든 조합의 최대 출력이나 true peak를 보장하는 값이 아니다.

## 기능과 검증의 경계

점검에서 확인한 코드 결함은 위와 같이 처리했다. 다음은 원래 보고서의 확장 제안 또는 실물 검증이며 이번 수정에서 구현했다고 주장하지 않는다.

- 실제 오디오 구간을 캡처하는 DJ 루프 롤: 현재는 명확히 안내된 노트 반복 기능.
- 자동 BPM 감지·time-stretch·연주 전체 녹음: 별도 확장 기능. 현재 원곡 BPM·첫 박 수동 입력, 원곡 속도 재생, 마이크 녹음 및 유니팩 내보내기 제공.
- 실물 Launchpad·휴대폰 멀티터치와 장치 왕복 지연: 물리 기기 실측은 미수행. 소프트웨어 입력과 화면 크기를 검증.
- LUFS·true peak·청감 최종 마스터링: 이번 측정은 sample peak/RMS와 동작 회귀 검사.

앱은 계속 외부 런타임 라이브러리 없이 `index.html`만으로 실행된다. 기존 MP3 및 곡 생성 스크립트는 변경하지 않았다.
